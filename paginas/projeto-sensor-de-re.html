Sensor de Ré

Circuito com Arduino que avisa a distância com luz e som.

Objetivo

Avisar, com luz e som, que existe um obstáculo perto.

Tecnologias

Arduino UNOSensor ultrassônicoLEDsBuzzerArduino IDE

Vídeo do projeto

Demonstração do circuito funcionando, com o LED vermelho aceso, e do código aberto no computador.

Componentes

  • Arduino UNO: recebe a leitura e comanda os avisos
  • Sensor ultrassônico: usa o eco do som para medir
  • Três LEDs: verde, amarelo e vermelho
  • Buzzer: parte sonora do alerta
  • Protoboard e fios: montagem do circuito

Como funciona

  1. O sensor mede a distância pelo tempo de ida e volta do som.
  2. O Arduino recebe a medida em centímetros.
  3. O programa testa as faixas de distância, uma por vez.
  4. Abaixo de 5 cm, o alerta é o mais forte: LED vermelho e som de 3000 Hz.
  5. Se nenhuma faixa se aplica, tudo é desligado.

O código

Parte do programa que aparece no vídeo. A variável distanciaCM decide o que acontece com os LEDs e com o buzzer.

else if(distanciaCM < 5) {
  digitalWrite(ledVermelho, HIGH);
  tone(buzzer, 3000);
}
else {  // desliga todos os LEDs e o buzzer
  digitalWrite(ledVerde, LOW);
  digitalWrite(ledAmarelo, LOW);
  digitalWrite(ledVermelho, LOW);
  noTone(buzzer);
}

O que aprendi

Vi na prática como um sensor, um programa e alguns LEDs funcionam juntos. O código decide o que fazer a partir da distância medida.
