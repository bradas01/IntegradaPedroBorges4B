Formação Técnica / Front-End

Front-End

O que cada linguagem faz neste site.

HTML

Define o que é cada parte da página: cabeçalho, menu, seções, imagens e rodapé. As tags section, article e figure dão sentido ao conteúdo.

<figure>
  <img src="..." alt="...">
  <figcaption>Crédito</figcaption>
</figure>

CSS

Cuida da aparência. O Grid distribui os cards, o Flexbox alinha o menu e as variáveis guardam as cores.

.grade-cards {
  display: grid;
  grid-template-columns:
    repeat(auto-fit, minmax(220px, 1fr));
}

JavaScript

Responde aos cliques: abre o menu no celular e movimenta os carrosséis.

botaoMenu.addEventListener("click", function () {
  menu.classList.toggle("aberto");
});

Meu projeto: este portfólio

São 29 páginas com o mesmo cabeçalho, o mesmo rodapé e um único arquivo de estilo. A estrutura parte do modelo apresentado em aula e foi organizada com as minhas áreas, projetos, fotos e certificados.

As imagens ficam separadas por assunto, e o layout se ajusta ao computador e ao celular.
